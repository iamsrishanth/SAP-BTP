## Focused check when Joule is unavailable

1. Inspect SAP Build Code subscription and the user's Build Code Developer role in the current subaccount.
2. Inspect the actual BAS plan, devspace type, and installed SAP extensions. Do not infer type from a name such as `Full_Stack`.
3. Look for the documented Joule activity-bar panel and its supported slash commands. A generic **Ask in Chat** command alone is not proof that SAP Build Code Joule is active.
4. If the relevant SAP extension is available to add, the documented Dev Space Manager edit workflow requires stopping the devspace, editing additional extensions, saving, and restarting. Preserve current workspace content and avoid interrupting an active build/server without coordinating it.
5. Record the actual missing capability/entitlement/error and the smallest required administrator/user action. Do not invent a hidden setting or repeatedly submit unchanged requests.

The official sources inspected do not establish that a devspace of the generic Full Stack Cloud type categorically cannot run Joule. That conclusion would require actual type/extension/plan evidence. Current observations, rather than this source index, establish those workspace outcomes.
